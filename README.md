# 日本語の語彙選択・連語誤用の検出

AIが出した誤った日本語をリアルタイムで位置付き指摘し、可能なら訂正案を出すツールを開発しています。技術文書・一般文の不自然な語の組み合わせや語彙選択を重点に、スクリプトからの自動呼び出しとtextlintへの接続を想定しています。

現在は、既存解析から原語・格関係・原文位置を取得し、既成の用例資料へ照合する経路を確認しています。[人手訂正9対の確認](docs/independent-pairs-check.md#完了結果)後に判明した解析遅延と本文欠落に対応し、[訂正した4全文で指摘負担を確認する工程](docs/full-text-support-check.md#訂正した接続で全文確認を再開する)です。目的に合う検出器の成立はまだ実証していません。正用同士の意味差や名詞単体の未収録を、対象の連語誤用と混同しません。独自の構文規則を含む初期試作はscratchへ隔離済みです。
