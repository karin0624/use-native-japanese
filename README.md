# 日本語の語彙選択・連語誤用の検出

AIが出した誤った日本語をリアルタイムで位置付き指摘し、可能なら訂正案を出すツールを開発しています。技術文書・一般文の不自然な語の組み合わせや語彙選択を重点に、スクリプトからの自動呼び出しとtextlintへの接続を想定しています。

現在は、目的から必要な情報と処理を分け、既存研究に基づく構成を検討しています。製品方式は未採用です。名詞が何を指すか、その対象に原文の述語をどう使うか、用例がその使い方を支えるかを分け、設計上の情報欠落を学習前に確認しています。独自の構文規則を含む初期試作はscratchへ隔離済みです。
