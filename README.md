# 日本語の語彙選択・連語誤用の検出

AIが出した誤った日本語をリアルタイムで位置付き指摘し、可能なら訂正案を出すツールを開発しています。技術文書・一般文の不自然な語の組み合わせや語彙選択を重点に、スクリプトからの自動呼び出しとtextlintへの接続を想定しています。

現在は、既存解析から原語・格関係・原文位置を取得し、既成の用例資料へ照合する経路を確認しています。次の評価では[単一の解析経路](docs/parser-connection-check.md)を使い、参照にない通常使用への[名詞側の支持](docs/nominal-support-check.md)を検証しています。目的に合う検出器の成立はまだ実証していません。正用同士の意味差や名詞単体の未収録を、対象の連語誤用と混同しません。独自の構文規則を含む初期試作はscratchへ隔離済みです。
