# 日本語の語彙選択・連語誤用の検出

AIが出した誤った日本語をリアルタイムで位置付き指摘し、可能なら訂正案を出すツールを開発しています。技術文書・一般文の不自然な語の組み合わせや語彙選択を重点に、スクリプトからの自動呼び出しとtextlintへの接続を想定しています。

現在は研究に基づく方式比較と、既存の人手注釈を利用する評価の準備を進めています。製品方式は未採用です。公開モデルの限定評価を踏まえ、用例による検出と専用の教師あり検出を検証します。独自の構文規則を含む初期試作はscratchへ隔離済みです。
