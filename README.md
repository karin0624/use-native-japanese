# 日本語の語彙選択・連語誤用の検出

AIが出した誤った日本語をリアルタイムで位置付き指摘し、可能なら訂正案を出すツールを開発しています。技術文書・一般文の不自然な語の組み合わせや語彙選択を重点に、スクリプトからの自動呼び出しとtextlintへの接続を想定しています。

現在は、語の使い方と比較単位・評価資料の対応を見直し、[人間の訂正と独立用例を使う限定照合](docs/lexical-usage-validation.md)を進めています。構造の保存と索引の動作は確認しましたが、目的に合う検出器の成立はまだ実証していません。正用同士の意味差や名詞単体の未収録を、対象の連語誤用と混同した設計判断を修正しました。独自の構文規則を含む初期試作はscratchへ隔離済みです。
