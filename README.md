# 日本語の語彙選択・連語誤用の検出

日本語の技術文書・一般文から、不自然な語の組み合わせや語彙選択を検出し、位置付きで指摘するツールを検討しています。スクリプトからの自動呼び出しと高速な反復実行を必須条件とし、textlintへの接続を想定しています。

現在は既存研究・ライブラリを比較する調査段階で、製品方式は未採用です。検索、コーパス統計、BERTなどは候補手段として扱っています。公開モデルの限定評価は完了していますが、採用決定ではありません。初期試作はscratchへ隔離済みです。
