# 日本語の語彙選択・連語誤用の検出

AIが出した誤った日本語をリアルタイムで位置付き指摘し、可能なら訂正案を出すツールを開発しています。技術文書・一般文の不自然な語の組み合わせや語彙選択を重点に、スクリプトからの自動呼び出しとtextlintへの接続を想定しています。

現在は、Juman++・KNPの解析を既成の格フレームへ接続し、[一般文・技術文4全文の照合と支持計算](docs/full-text-support-check.md#全文結果と次の限定調査)を完了しました。通常本文でも支持が低くなる例について、参照情報の未利用と比較方式の性質を分けて確認しています。目的に合う指摘判断とリアルタイム動作はまだ実証していません。正用同士の意味差や名詞単体の未収録を、対象の連語誤用と混同しません。独自の構文規則を含む初期試作はscratchへ隔離済みです。
