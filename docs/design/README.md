# 設計のテンプレート

全体構成はarchitecture.md、用法照合はusage.mdへ置く。別の機能を独立して説明する必要があれば、機能名のファイルを追加する。

## 全体構成

```markdown
# システムの構成

## 構成と責務
部品ごとの入出力、責務、依存先。

## データの流れ
入力から結果までの処理と保存先。

## 実行・配布
起動、資源、更新、配布の境界。

## 採用理由
選定を支える技術的根拠と代替案との差。
```

## 機能

```markdown
# 機能名

## 目的と対象外
必要な振る舞いと、扱わない問題。

## 入出力
利用者から見た契約。

## 方式
処理の構成、不変条件、失敗時の扱い。

## 根拠と制約
採用理由、一次資料、成立範囲、未対応。
```
