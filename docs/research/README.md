# 調査知見のテンプレート

先行研究の比較はprior-research.mdへ置く。別の技術課題に継続参照する比較が必要なら、課題名のファイルを追加する。

```markdown
# 調査対象

## 問いと比較条件
何を判断するための比較か。対象言語・入力・出力・評価単位。

## 比較
| 資料・対象版 | 課題・方式 | 得られる知見 | 適用の限界 |
| --- | --- | --- | --- |
| 一次資料へのリンク | 対象と手法 | 資料が裏付けること | 裏付けないこと |

## 結論
再利用できる原理と成立条件。資料間で比較できない点。
```

技術選定では比較軸に機能・互換性・保守・費用を加える。
