# 連語・語彙選択誤り検出の先行研究

## 問いと比較条件

日本語の自由文から語の使い方の誤りを位置付きで検出するための研究と評価資料を比較する。[製品全体の目的](../../README.md)のうち、述語と組み合わせの用法照合に関する資料を扱う。全文からの検出、既知箇所の訂正候補推薦、句の自然さ評定は、入力と評価単位が異なる。

### 類似度平均と平均方向

[Erkほか2010 §3.1式(6)](https://aclanthology.org/J10-4007.pdf)は、用例との類似度の加重平均であり、cosineの負値も保持する。単位ベクトル`x, v_i`、重み`α_i ≥ 0`（合計1）、`m = Σ α_i v_i`について、次が成り立つ。

```text
用例cosineの加重平均 = Σ α_i (x・v_i) = x・m
平均方向とのcosine  = (x・m) / ||m||     （m ≠ 0）
```

後者は平均ベクトルを再正規化するため、両者は一般に同値ではない。負のcosineを0へ置き換える処理も、符号付き平均とは別の計算である。

### 同じ出現での共同観測

[Goldberg・Orwant 2013 §3](https://aclanthology.org/S13-1035.pdf)の比較単位は、同じ文の依存木に属する連結した部分木である。同じ主辞に複数の辺が結び付く条件は、同じ出現の語群で満たす必要があり、辺ごとの件数や同文内の共起では代替できない。

### 格フレームと用例索引

[河原・黒橋2005](https://nlp.ist.i.kyoto-u.ac.jp/member/kawahara/paper/NLP-CaseFrame2.pdf)は、構文曖昧性の低い述語項構造を選別・クラスタリングして格フレームを構築する。[林部ほか2015 §5.2](https://hayashibe.jp/publications/NL224.pdf)は、低頻度の項、小さい初期フレーム、格が一つの初期フレームを除去する。

格フレームは原資料の全用例を保持する索引ではなく、未収録を日本語全体での不存在とはみなせない。別の参照資源として利用するには、対象配布版の採録条件、述語単位、表記、格の定義の互換性を確認する必要がある。

## 結論

用例照合の被覆、解析した語と関係の正しさ、類似度による一般化を分けて評価できる資料が必要である。
