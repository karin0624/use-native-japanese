# 現在の完成条件と検証

語の組合せを用例に照らし、確認が必要な名詞・述語を位置付きで返すツールを実装しました。利用は[セットアップ](setup.md)から[本体のprepare・lint・常駐API](runtime.md)、[textlint](textlint.md)へ進めます。[実経路と用例追加の検証結果](runtime-validation.md)に、今回の完成条件への到達と残る制約を記載しています。

## 今回の完成条件

実際の解析・照会・指摘経路を通し、所定形式の出典付き実用例を追加すると改善できること、保存・取込・照会の費用が規模に応じて拡大可能であることを示します。全例の正答や、必要な用例が未収録のケースの解決は求めません。情報不足と方式・実装の不備を分けます。

[固定した実装・検証方針](incremental-runtime.md)に従い、同じコード・境界・評価入力で追加前後を比較しました。評価前に入力と別出典を固定し、改善・悪化・無変化・不能を報告しています。評価入力そのものや手作業の正解用例の登録を改善証拠にしていません。保存量と費用の構造に段階的な実用例追加の測定を併記し、少量の結果だけで大規模性能を保証しません。

## 固定した判断

Juman++・KNPの標準確率CV解析と公開PAS、F/C/N/Hの接続条件を維持し、同じ出現の述語・型・格・名詞を照会します。文法・活用・助詞の独自規則や例文別の補修は追加しません。

直接観測があれば指摘しません。直接観測がなく比較可能な通常frameがある場合、名詞群の方向への類似度Dを求め、通常frame・公開候補間の最大を使います。暫定境界は **D < 0.35** に固定します。Dは正誤確率ではなく、比較不能・厳密zero・非有限値は数値0にせず理由を残します。既使用の診断で境界を選んだため、その資料を独立最終評価とは扱いません。

## 実装と検証の状況

Pythonの`Inspector.analyze`／`lint`／`lint_many`、CLIの`prepare`／`lint`／`serve`／`extract`／`import`、既存textlintとの実接続を実装しました。解析器と参照は常駐して再利用し、Python内部は文字添字、JSON出力はUTF-16に統一しています。出典付きJSONLの追加用例はSQLiteへ保存し、直接支持へ加えます。native起動前検証と固定vectorのloaderはsetup・本体で共有しています。

実統合、別出典追加前後、段階的な取込費用の検証を完了しました。固定38本文のうち37本文を前後比較し、1本文は上流の形式エラーで比較不能として残しています。別記事から抽出した222件の追加で、正用への不要な指摘1関係が解消し、主対象への指摘は維持されました。誤った解析関係への指摘も1件消えましたが、改善には数えていません。

追加保存は情報量に比例する構造で、64／128／256件の実用例を使って取込・照会・冪等性を確認しました。原語・格・位置付き指摘への到達、直接観測の対照、Unicode・Markdown・常駐経路も確認済みです。fresh contextの全体レビュー後の必須修正を反映し、Python62件と19補助ケース、textlint18件が成功しています。

初期化・初回の群準備・再検査は分けて記録しました。200文字以内の再検査1秒以内という測定目標には届かないケースがあり、12文字で7.96秒、25文字で9.45秒でした。この2件ではnative解析器の応答待ちが主でした。現在の構成で一般のリアルタイム性を保証しません。

## 残る制約

- 直接用例の追加だけを扱い、群平均の更新や未追加語への一般化、訂正案は未実装です。抽出された用例の正しさは解析器だけでは保証できず、出典選定と原文確認が必要です。
- Dには既知の誤支持があります。診断ではラベル・機関車の通常使用の支持が回復する一方、ネックレスの着る／持つの区別は悪化しました。完全分離を終了条件へ追加しません。
- 既存解析が元の語や関係を保てない例と、技術文の`>`を含むKNP出力をrhoknpで読めない例が残ります。用例追加で解決する問題とは扱いません。適用資料での原因別の結果は[検証記録](runtime-validation.md#固定資料への適用と追加前後)を参照してください。
- 既成CDBの複合aliasには組合せ積による構築時間の制約が残ります。平均だけを保存し、追加flat用例をその展開へ入れません。費用の式とcacheの分離は[保存量と実行費用](incremental-runtime.md#保存量と実行費用)を参照してください。
- Markdownの文字参照・escapeには未検査になる範囲があります。[位置と検査範囲](textlint.md#markdownの位置と検査範囲)に制約を残しています。
- 大容量資源はローカル準備が必要です。確認済みの再利用buildと未試行の初回経路、再配布条件の未確認事項は[セットアップ](setup.md#出自と確認範囲)を参照してください。
