# 参照仕様のテンプレート

textlintの設定・位置対応はtextlint.md、Python・CLI・用例形式はruntime.mdへ置く。

## API・CLI

```markdown
# API・コマンド名

## 入出力
引数・型・必須条件・既定値・戻り値。

## 使用例
最小の呼び出しと、結果の意味。

## エラー
発生条件と呼び出し元の扱い。

## 制限
互換性、対象外、未対応の入力。
```

## 設定・データ形式・通信

```markdown
# 設定・形式・プロトコル名

## 項目
名前、型、必須条件、既定値、意味。

## 例
有効な最小例。

## 契約
文字コード、位置単位、順序、寿命などの成立条件。

## 失敗時の扱い
不正値・不整合・通信失敗の処理。

## 制限
対応範囲と互換性。
```

## 帰属表示

```markdown
# 同梱資源と依存ソフトウェアの帰属

## 資源名
作者・取得元・元資料・ライセンス・当方の変更内容。
資源の版とハッシュを管理するmanifestへの参照。

## 依存ソフトウェア
名前、提供者、適用条件、同梱するライセンス原文。

## ライセンス原文の取得元
原文ファイルと取得元の対応。
```
